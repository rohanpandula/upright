1. PROTOCOL AND METRIC
Primary raw clone distance: RMS pixel displacement over the existing fixed 25x25 source grid, including
all four corners, divided by ORIGINAL source diagonal, times 100. No fitted translation, scale, rotation,
crop or shape alignment is removed from the primary score. NumPy linear-interpolated percentiles.
Each real photo contributes paired Auto and Full results, seed=0. Both option settings are fresh actual
solve_ex calls, same supports/prior/seed; failed solves are retained as their returned identity. A photo
is counted catastrophic if either mode exceeds 5%; an attempt is catastrophic if its raw score exceeds 5%.
The heldout renderer is unchanged, and no four-scene data is loaded by this benchmark. All four automatic
modes are tested on heldout seeds 0..4. Ground-truth quads are a policy-only control, never solver input.
There are NO Adobe native transforms for these 14 scenes in this test; heldout safety and known-geometry
agreement cannot establish that Adobe would select the same branch/zoom. No native GUI solve was run.

a translated quad whose centre is off-frame can remain entirely off-frame if framing is omitted.
