VERDICT
-------
The stated empirical formula  focal_px = f35 / 36 * max(W,H)  is a
COINCIDENTAL special case. The real conversion is DIAGONAL based:

    focal_px = f35 * hypot(W, H) / hypot(24.0, 36.0)
             = f35 * diag_px / 43.2666153

i.e. a 36x24 mm full-frame sensor used via its 43.2666 mm diagonal — NOT the
36 mm long edge, and NOT the width. 43.2666 is never a literal: it is always
computed at runtime as hypot(24,36) (PROOF: zero 43.266 literals exist).

The two formulas agree exactly at 3:2 because 43.2666153/36 == sqrt(13)/3 ==
1.2018504251546631 (PROOF, computed). They diverge for every other ratio:
    aspect   effective long-edge divisor   error vs /36
    3:2      36.000                        0.0 %
    4:3      34.613                       -3.9 %
    5:4      33.786                       -6.2 %
    16:9     37.710                       +4.8 %
    2:1      38.699                       +7.5 %
    1:1      30.594                      -15.0 %
So: keep the long-edge form only if the pipeline is guaranteed exactly 3:2.

3. 35 mm NORMALISATION DIVISOR / MULTIPLIER PAIRS
------------------------------------------------
There is no "divide by 36" anywhere. The 43.2666 diagonal is computed four
times inside this one function and used both ways:

  a) mm -> px, site above:  ratio = diag_px/43.2666 ; focal_px = f35*ratio
  b) px -> mm, 0xb623a0-0xb623b9: xmm0 = hypot(24,36);
     0xb623a5 xmm1 = [rbp-0xe70]; 0xb623ad divsd xmm1,xmm0;
     0xb623b1 mulsd xmm1,[0x321ebb0] (= 35.0) -> a 35 mm-equivalent pixel
     length, stored back to [rbp-0xe70]
  c) 0xb6245e-0xb62473: xmm0 = hypot(24,36); 0xb62463 divsd xmm0,[rbp-0xe80];
     0xb62473 divsd xmm3,xmm0 -> mm from px
  d) 0xb624f0-0xb62509: xmm0 = hypot(24,36); 0xb624fd divsd xmm3,xmm0;
     0xb62509 mulsd xmm0,xmm3
  e) inverse scale also at 0xb68257: divsd xmm0,[rbp-0x3ef0] (px/mm)

So the pair is (diag_px, 43.2666) => px-per-mm and mm-per-px. The literal 36
never participates in a division.
