UPDATE — GUIDED IS NOW FULLY DRIVABLE FROM THE PLUGIN (no line drawing)

The original conclusion "needs GUI line-drawing because flushDirtyUprightGuides is
internal" was too pessimistic. It needs one click, not four drags.

Mechanism (from digest.txt): the host calls enableUprightReanalyze, which returns
"must recompute" iff mode != 0 AND digest(now) != stored_digest, and for guided
additionally requires the guide vector non-empty. Writing settings from a plugin
does NOT by itself invoke that check — so a bare settings write is silent.
But if the digest is zeroed, a subsequent explicit re-analyse (the panel's Update
button) always finds a mismatch and always solves.
